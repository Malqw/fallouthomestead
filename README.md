# Homestead Builder

Фанатский билдер под аддон настольной игры Fallout Wasteland Warfare / Homestead 

## Как это работает
- **Поселение** - Режим постройки зданий по правилам Fallout Homestead (большая часть правил автоматизирована и проходит валидацию)
- **Отряд** - Добавление юнитов в ростер + доп. правила из Fallout Homestead
- **Склад** - В обычном режиме вещи на юниты добавляются из склада, т.е чтобы добавить предмет на юнита, нужно сначала его добавить на склад. 
  Так же при удалении юнита или предмета с юнита все эти вещи переносятся на склад

- **Данные хранятся в браузере** (`localStorage`), на конкретном устройстве. Никакого входа,
  никакого сервера — заходишь и сразу работаешь. Открыл с телефона — там будут свои отдельные
  данные (это НЕ синхронизируется между устройствами).
- **⭳ Скачать JSON / ⭱ Загрузить JSON** (кнопки в Отряде/Поселение) — так переносишь сохранение между
  устройствами или делишься отрядом с другом: скачал файл на одном устройстве, загрузил на другом.
- **🃏 Карточки** — у юнитов, предметов, перков и модов есть кнопка просмотра настоящей карточки
  (покрытие ~100%). Картинки лежат в `cards-web/` (сжатые WebP, ~33 МБ), подгружаются только по
  клику, не все разом.
- **🖨 Печать состава** — раскладка ростера картинками карточек вместо текста (только бойцы с
  отметкой «Миссия»). Все настройки размеров — в коде, см. функцию `printSquadRoster()`.
- **🎵 Радио Пустошей** — список треков зашит в код (`MUSIC_TRACKS` в начале секции музыки),
  файлы лежат в `music/`. Чтобы добавить песню: положить mp3 в `music/` и дописать
  `{file, title}` в массив `MUSIC_TRACKS` вручную.

## Локальный запуск для проверки

Открыть `index.html` напрямую двойным кликом почти сработает, но браузеры блокируют некоторые
вещи для `file://` (в частности `fetch`/`Audio` в некоторых случаях) — надёжнее поднять любой
локальный статический сервер в этой папке, например:

```
python -m http.server 8000
```

и открыть `http://localhost:8000`.
